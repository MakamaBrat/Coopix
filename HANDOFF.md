# HANDOFF — Coopix Market

Стек: Vercel serverless (`api/`), Supabase (ключ service_role только на сервере), клиент `public/index.html`, админка `public/admin.html`.

## Проверено
- `npm test`: 68 проходят. 3 теста в `tests/handlers.test.js` падают только из-за пакета `@vercel/functions`, который не ставится без сети. С сетью: `npm i`.
- Браузерные e2e (Playwright, сервер с настоящим core на in-memory store): 35 + 15 + 19 + 20 проверок, все проходят. Скрипты были вне репозитория и в архив не входят.

## Сделано
- Каталог игр на сервере. Права: главный админ правит всё сразу, автор своей игры через одобрение («Правки страниц»), остальные не правят ничего.
- Обложка 512×512 и фон-картинка 1280×720 хранятся на сервере (`cover_img`, `bg_img`), отдаются отдельно (`hub?r=cover[&kind=bg]`), на клиенте кэшируются по хэшу.
- Моды: таблица `game_mods`, маршруты `hub?r=mods|modfile|mod|mymods`, `admin?r=mods|mod`, вкладка на странице игры.
- «Спасибо автору»: `api/_lib/thanks.js`, `api/bot.js` (вебхук с секретом), `hub?r=thank`, `admin?r=webhook`, таблица `thanks`.
- График: реальная ширина, звёзды, без лишних подписей, компактный. Журнал только для staff.
- Сортировка и фильтры магазина по двум рейтингам (оценки отзывов и поддержка). Поддержка показывается золотыми пиксельными блоками, а не звёздами.
- Интерфейс переведён на русский (редактор, настройки, поиск, тосты).

## Добавлено поверх (Claude Code, 10.11)
- Ник = имя из Telegram, менять нельзя: сервер берёт его из проверенного initData (`tgName` в `hub.js`), присланный клиентом ник игнорирует; в редакторе профиля поле только для чтения.
- Аватар из Telegram: `hub?r=tgphoto` (бот: `getUserProfilePhotos` → `getFile` → файл через `tgFile` в `runtime.js`), клиент уменьшает до 128×128 и раз в сутки обновляет, пока игрок не поставил свой аватар («Голубь» или загрузка).
- `store.saveGame`: вместо upsert — update, а если строки нет, insert (upsert с частью полей падал бы в Postgres на NOT NULL `title`).
- `index.html`: при окне 0×0 на старте `drawBg` больше не останавливает цикл анимации.
- Тесты: 70 проходят (+3 в handlers после `npm i`).

## Скорость загрузки (11.11)
- Спрайты предметов: файлы `public/assets/spr/*.png` с кэшем на год (`vercel.json`), а не 700 КБ base64 в блокирующем `assets/sprites.js` (файл больше не подключается). Геометрия `FACES`/`DECOR` перенесена в `index.html`. Меняете картинку — переименуйте файл, иначе у игроков останется старая.
- `/api/hub?r=config` = `/api/config`: на старте маркет будит одну функцию Vercel вместо двух.
- «Кто это» (`touch_user`, запись в базу) кэшируется на 30 с в экземпляре функции; старт маркета, `/me` и админка всегда идут в базу, бан и модератор сбрасывают кэш сразу.
- Самое заметное, что осталось сделать в Vercel: Settings → Functions → Region = регион проекта Supabase (по умолчанию функции в США, и каждый запрос к базе летит через океан).

## График «Пульс маркета»
Только ключевые действия: регистрация, новый отзыв, первый запуск и первая загрузка игры игроком (SQL `activity_series`, индекс `events_first_idx`). Звёзды — отдельной строкой. Нужно перезапустить `supabase/schema.sql`.

## Деплой
1. Выполнить `supabase/schema.sql` целиком.
2. Задеплоить.
3. Админ-панель → «Звёзды» → «Подключить приём звёзд».
