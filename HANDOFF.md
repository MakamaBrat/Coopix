## График «Пульс маркета»
Только ключевые действия: регистрация, новый отзыв, первый запуск и первая загрузка игры игроком (SQL `activity_series`, индекс `events_first_idx`). Звёзды — отдельной строкой. Нужно перезапустить `supabase/schema.sql`.

## Деплой
1. Выполнить `supabase/schema.sql` целиком.
2. Задеплоить.
3. Админ-панель → «Звёзды» → «Подключить приём звёзд».

## Карты игроков в облаке и ссылка «поделиться» (Noomic Bot)
- Таблица `game_maps` (`supabase/game_maps.sql`, она же в конце `schema.sql`): до 3 карт на игрока и игру, код карты ≤ 24 КБ (обычно 1,5–13 КБ), до 400 деталей. Выполнить один раз: SQL Editor или `python scripts/run_sql.py supabase/game_maps.sql` (нужен `SUPABASE_ACCESS_TOKEN`).
- Сервер: `api/_lib/maps.js` (разбор и чистка кода `NC1-…`: типы деталей, диапазоны, до 400 деталей; сохраняется заново собранный код) и маршруты hub: `mymaps` (мои карты), `mapput` (создать/обновить свою, лимит 3, ≤20 записей в минуту), `mapget` (открыть по id), `mapdel` (удалить свою). Тесты: `tests/maps.test.js`.
- Маркет (`public/index.html`): `gameMaps` принимает от игры сообщения `{coopix:"maps", op: list|put|get|del|share, rid}` и отвечает тем же `rid`; `share` открывает окно «Поделиться» Telegram со ссылкой `t.me/<бот>?startapp=map_<id>`. По такой ссылке маркет сразу запускает игру карты и кладёт карту в `window.__CPX_MAP`.
- Игра (`games/noomicbot/maps.js`): у каждой карты в конструкторе кнопка «Поделиться» (сохраняет в облако и открывает отправку), блок «Облако N/3» (поделиться, взять в «Авторские», удалить), карта из ссылки добавляется в «Авторские» и запускается.
- Модерации карт нет: карта открывается только по ссылке с неугадываемым id; удалить может автор. Если понадобится, добавить в админку список и удаление.
- Порядок выкладки: SQL → деплой API и маркета → публикация игры. Пока таблицы нет, облако в игре просто покажет «Нет связи».

## Перехваты и рекорд серии на сервере (Noomic Bot)
- Таблица `game_stats` (`supabase/game_stats.sql`, она же в конце `schema.sql`): одна строка на пару игрок—игра (`regrabs`, `best_streak`). Выполнить один раз: SQL Editor или `python scripts/run_sql.py supabase/game_stats.sql`.
- Сервер: `api/_lib/stats.js` (слияние) и маршруты hub `mystats` (прочитать) и `statput` (записать). Числа только растут; рост за раз ограничен по времени (запас 50 + ~3 перехвата в секунду), рекорд серии не больше числа перехватов, не больше 30 записей в минуту. Первая запись игрока принимается почти как есть (до 1 млн): так переезжает прогресс, накопленный до серверного хранения. В базу пишется только при росте, нулевые значения не пишутся. Тесты: `tests/stats.test.js`.
- Маркет: при запуске игры отдаёт ей `window.__CPX_STATS` (вместе со списком купленного), на сообщение игры `{coopix:"stats"}` пишет на сервер и отвечает сохранёнными значениями.
- Игра (`games/noomicbot/stats.js`): берёт большее из локального и серверного, при росте раз в 3–8 с шлёт значения маркету, при сворачивании шлёт сразу. Вне маркета (просто файл) всё остаётся как раньше, в локальном сохранении.
- Порядок выкладки: SQL `game_stats` → деплой API и маркета → публикация игры. Пока таблицы нет, игра работает как раньше (перехваты в локальном сохранении).

## Коронная фраза и стили надписи (Noomic Bot)
- Вкладка «Фраза» на экране «Скины»: поле до 25 символов, 8 анимированных стилей надписи и превью. Фраза показывается вместо названия жеста в игре и в повторе (в конфиг повтора пишется `ph:{t,s}`, повтор из файла проходит через обёртку `cleanEv`).
- Цены: `ph_phrase` — 5⭐ (сама фраза, в покупку входит стиль 0 «Золото»); стили продаются отдельно: `ph_s1..ph_s7` = 5, 5, 10, 10, 15, 20, 25⭐ (Неон, Огонь, Лёд, Радуга, Комикс, Глитч, Голограмма). Цены лежат в `items.json` и попадают в `api/_lib/items.js` при сборке — **нужно задеплоить API**, иначе сервер не примет покупку.
- Пока стиль не куплен, его можно примерить в превью; в игре вместо неоплаченного стиля показывается «Золото». Код: `gestures.js` (`showPhrase`, `phraseOf`, CSS `.phs0..7`), `skins.js` (`renderPhrase`), тексты — `PH` в `i18n.js` (ru/uk/en, остальные языки пока на английском).
- Надписи собираются из букв: у каждой буквы слои контура/объёма (`::before`), заливки с бликом (`::after`) и частицы стиля (искры, угольки, снег, комикс-взрыв, глитч-«сборка» букв). Всё в `gestures.js` (`phRender`, `phSet`, `showPhrase`, CSS `.phs0..7`); размеры обводки в `em`, поэтому масштабируются с размером текста. Для «Огня» в документ добавляется SVG-фильтр `#phFlame`.
- Ввод фразы — отдельное окно `#phEd` (поле + кнопка «Готово» вверху, живое превью ниже), чтобы клавиатура ничего не закрывала. Текст сохраняется на каждую букву: `SAVE.phDraft` (черновик, даже до покупки), `SAVE.phrase` (после покупки), выбранный стиль — `SAVE.phSel`.
- Длинная фраза (больше 13 символов) переносится на две строки по пробелу ближе к середине (`phLines`); размер считается по самой длинной строке и дополнительно подгоняется по замеру (`offsetWidth`), чтобы надпись (и взрыв «Комикса») не выходила за экран или панель превью.
- Упрощение для слабых телефонов: убраны SVG-фильтр огня, размытие, `mix-blend-mode`, анимации каждой буквы и `hue-rotate`. У букв только короткое появление, постоянная анимация — одна на всю надпись (transform/opacity); частиц мало; карточки стилей в списке статичные. Шрифт простой: Roboto / Segoe UI / Arial Black (без Impact, его нет на Android), ширина подгоняется замером.

## Карта по коду и освещение (Noomic Bot)
- У каждой облачной карты есть короткий код из 12 знаков (id на сервере, показывается как `A1B2-C3D4-E5F6`). Кнопка «🔑 Код» у карты в конструкторе кладёт её в облако и показывает код с кнопкой «Копировать»; в блоке «Облако» код виден в строке карты. В главном меню — кнопка «🔑 По коду» (`maps.js`, окно `#cdBox`): вставить код → карта берётся с сервера (`hub?r=mapget`, он открыт для любого игрока), добавляется в «Авторские» и сразу запускается. Длинный код `NC1-…` тоже принимается и работает вне маркета. Сервер не менялся (облако — 3 карты на игрока).
- Освещение: автоснижение качества (`QL`) больше не выключает тени полностью (раньше через ~10 секунд при лагах `shadow:n.shadow&&QL<3` убирало тени и «освещение уходило»), а выключение теней идёт через `sun.castShadow`, а не `renderer.shadowMap.enabled` (последнее требует перекомпиляции материалов).
- Поля ввода (`#phIn2`, `#cdIn`) обязаны иметь `user-select:text; touch-action:auto`, иначе в игре (где глобально `user-select:none`) на телефонах не печатается.
